# Shahbazi Store — Artisan Botanical Perfume Oils

Shahbazi Store is a digital e-commerce experience crafted for an independent artisan perfume house specializing in pure, zero-alcohol concentrated attar oils. The interface adheres to quiet luxury design principles, prioritizing refined typography, spatial harmony, and performance.

---

## Overview

The platform features an editorial layout system inspired by high-end fragrance houses. Key features include:

- **Quiet Luxury Aesthetic System**: High-contrast typography paired with soft cream (`#FAF8F5`), charcoal (`#1C1A17`), and muted gold accents (`#C5A880`).
- **Hero Carousel & Interactive Visuals**: Split-column landing layout with auto-cycling high-resolution product compositions linked directly to item detail views.
- **Dynamic Catalog Grid**: Responsive 4-column desktop and 2-column mobile layout for curated attar selections.
- **Scent Pyramid Breakdown**: Comprehensive scent node classifications (Top, Heart, Base notes) and bottle sizing selectors (`3ml`, `6ml`, `12ml Tola`).
- **Cart & Wishlist State Management**: Fully persistent cart drawer, order history tracking, and wishlist synchronization using React Context and `localStorage`.
- **Editorial Navigation**: Responsive mobile navigation drawer with structured numbered indices.

---

## Architecture & Technology Stack

- **Core Framework**: React 18 with TypeScript
- **Build Tooling**: Vite 5
- **Styling**: Tailwind CSS v3 with custom design tokens
- **Animation Engine**: Framer Motion
- **Iconography**: Lucide React
- **Client Routing**: React Router v6

## Getting Started

### Prerequisites

- Node.js (v18.0 or higher)
- npm (v9.0 or higher)

### Installation

```bash
# Clone the repository
git clone https://github.com/IsacSmile/jabazi-store.git
cd jabazi-store

# Install dependencies
npm install

# Launch development server
npm run dev
```

### Production Build

```bash
# Compile TypeScript and generate production assets
npm run build
```
